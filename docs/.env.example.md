# Documentation: @/.env.example

### Purpose
Provides a template of environment variable keys and sample values required to run the server, PostgreSQL/Supabase database connection, and encryption utilities.

### What happens without it
New developers or deployment pipelines will not know which environment variables must be defined.

### Variable definitions
- `PORT`: HTTP port for Fastify server (default 3001).
- `DATABASE_URL`: PostgreSQL / Supabase connection URL for Drizzle ORM (e.g. `postgresql://postgres:rootpassword@localhost:5432/squizme`).
- `JWT_SECRET`: Secret string used for signing and verifying user authentication tokens.
- `ENCRYPTION_KEY`: 64-character hex string (32 bytes) used for AES-256-GCM encryption of BYO Gemini API keys.
- `DEFAULT_GEMINI_API_KEY`: Host Gemini API key for users on the 2-free-quiz quota tier.
- `VITE_API_URL`: Client-side base URL pointing to the server API.
