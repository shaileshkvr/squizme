# Documentation: @/.gitignore

### Purpose
Specifies intentionally untracked files and directories that Git should ignore, such as node_modules, build outputs, and local environment files.

### What happens without it
Build artifacts, local secrets (`.env`), and gigabytes of dependency folders would be committed to source control.

### Ignore rules
- `node_modules`: Local dependencies installed by pnpm.
- `dist`: Compiled JavaScript and CSS artifacts.
- `.env`: Local sensitive credentials and secrets.
- `*.log`: Runtime log outputs.
- `coverage`: Test coverage reports.

### Dependency graph
- Depends on: None.
- Depended on by: Git version control.
