# Documentation: @/apps/client/src/pages/About.tsx

### Purpose
Publicly accessible about page presenting Squizme's core capabilities, document ingestion (20MB limit), Google Search grounding, Learning vs Exam modes, local device API key storage, and model privacy disclaimers.

### What happens without it
Prospective users and visitors cannot learn about Squizme's architecture, free tier boundaries, local key security, and key features.

### Sections
- Hero banner with quick start calls-to-action.
- Core capabilities grid: Document ingestion, prompt research, dual learning modes.
- Bring-Your-Own-Key model overview with local-only device encryption and Google Gemini independent terms disclaimer.
- Technical architecture highlights.
