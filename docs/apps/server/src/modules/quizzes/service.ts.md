# Documentation: @/apps/server/src/modules/quizzes/service.ts

### Purpose
Handles transactional quiz persistence, question batching, and quiz retrieval queries against PostgreSQL.

### What happens without it
Quizzes generated by AI or submitted manually cannot be saved or fetched by participants.

### Functions
- `createQuizWithQuestions(userId, title, description, sourceType, sourceMetadata, settings, questionList)`: Transactionally writes the quiz header and all associated questions into PostgreSQL.
- `listUserQuizzes(userId)`: Returns all quizzes created by a user, ordered by creation timestamp descending.
- `getQuizById(quizId)`: Retrieves a quiz record together with its ordered questions.
