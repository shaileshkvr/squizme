# Documentation: @/.dockerignore

### Purpose
Excludes non-essential directories and files (`node_modules`, `.git`, `.env`, build artifacts, documentation, and agent task logs) from being transferred into the Docker daemon context during container build.

### What happens without it
The Docker daemon context expands to dozens or hundreds of megabytes, slowing down builds and potentially leaking development credentials or local host node_modules into the container filesystem.

### Excluded patterns
- `node_modules`
- `.git`
- `.env`
- `dist`
- `docs`
- `antigravity`
- `*.log`

### Dependency graph
- Depends on: None
- Depended on by: `Dockerfile`, Docker CLI build daemon
